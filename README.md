# 🖥️ CPU Job Scheduling Algorithms

A web-based application that demonstrates various **CPU Job Scheduling Algorithms** using **HTML, CSS, and JavaScript**. The application provides an interactive interface for simulating CPU scheduling techniques and comparing their performance through key scheduling metrics.

## 🚀 Features

- Interactive and user-friendly interface
- Simulate multiple CPU scheduling algorithms
- Displays scheduling results in tabular format
- Calculates and displays:
  - Average Waiting Time
  - Average Turnaround Time
  - Average Response Time
  - Throughput
  - Context Switches
- Responsive design for different screen sizes

## 📚 Algorithms Implemented

- ✅ First Come First Serve (FCFS)
- ✅ Shortest Job First (SJF)
- ✅ Shortest Remaining Time First (SRTF)
- ✅ Non-Preemptive Priority Scheduling
